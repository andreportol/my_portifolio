Privacidade e dados

Política de Privacidade

Última atualização: 15 de junho de 2026. Esta política explica como o site andreporto.up.railway.app trata dados pessoais e como lidar com pedidos de exclusão de dados, inclusive em cenários de integração com a Meta/Facebook.

1. Quem controla os dados

O responsável por este site e pelo tratamento de dados é André Luzardo Porto. Para contato sobre privacidade, use andreportol@gmail.com.br.

2. Dados que coletamos

Coletamos apenas os dados enviados voluntariamente pelo usuário por meio do formulário de contato, como nome, telefone, e-mail e assunto. Também podemos receber dados técnicos básicos do navegador e do servidor para segurança e funcionamento do site.

3. Dados da Meta/Facebook

Se uma funcionalidade com Meta/Facebook Login ou outra API da Meta estiver ativa, podemos receber apenas os dados autorizados pelo usuário e necessários para a função solicitada, como nome, e-mail, foto de perfil, identificador da conta e informações públicas permitidas pela Meta.

4. Finalidade do uso

Usamos os dados para responder contatos, operar recursos do site, autenticar usuários quando aplicável, cumprir obrigações legais, manter segurança e evitar abuso. Não vendemos dados pessoais.

5. Compartilhamento

Não compartilhamos dados pessoais com terceiros, exceto quando necessário para operação técnica do site, cumprimento de obrigação legal, resposta a solicitações do usuário ou uso de serviços essenciais, como hospedagem e e-mail.

6. Cookies e registros

Podemos usar cookies técnicos e registros de acesso para manter o site funcionando, medir estabilidade e reforçar segurança. Se ferramentas de terceiros forem ativadas, elas seguirão suas próprias políticas, que devem ser informadas ao usuário.

7. Retenção

Mantemos os dados somente pelo tempo necessário para a finalidade informada, para resposta ao usuário, para obrigações legais ou para defesa de direitos. Depois disso, eles são eliminados ou anonimizados quando possível.

8. Exclusão de dados

O usuário pode solicitar a exclusão dos dados enviados ao site ou recebidos via Meta/Facebook enviando um e-mail para andreportol@gmail.com.br com o assunto Exclusão de dados. Responderemos com as orientações e concluiremos a exclusão em até 30 dias, salvo obrigação legal de retenção.

9. Direitos do titular

O usuário pode solicitar acesso, correção, exclusão, revogação de consentimento e informações sobre o tratamento de dados. Quando aplicável, também é possível revogar permissões diretamente nas configurações da conta Meta/Facebook.

10. Segurança

Adotamos medidas técnicas e administrativas razoáveis para proteger os dados contra acesso não autorizado, perda, alteração ou divulgação indevida. Nenhum sistema é totalmente infalível, então a proteção é tratada de forma contínua.

11. Menores de idade

Este site não é direcionado a menores de 13 anos. Se houver coleta indevida de dados de menor de idade, o responsável legal pode solicitar a remoção imediatamente pelo e-mail de contato.

12. Alterações

Esta política pode ser atualizada a qualquer momento para refletir mudanças no site, nas integrações com a Meta ou em exigências legais. A versão publicada nesta página é sempre a válida.
